# 創建你的第一個存在證明

歡迎來到 Proof of Existence。這份指南帶你完成從登入到提交的完整流程，中途不需要任何加密貨幣知識。

> 用 Google 登入 → 進入畫布 → 畫超過 10 秒 → 點「Submit Proof」→ 選標準證明（免費）。完成。你的軌跡會在每日 UTC 00:00 被記錄到 Polygon 區塊鏈。

---

## 你需要準備什麼？

只需要一個網頁瀏覽器（Chrome、Firefox、Safari 或 Edge）。不需要加密錢包，不需要預先充值，不需要任何技術設置。

---

## 第一步：登入

訪問 [proofexistence.com](/) 並點擊右上角的「登入 / 連結錢包」。

### 社交登入（推薦新手）

用現有帳號登入：Google、Facebook、Apple、Line 或 X（Twitter）。

**Web3Auth 會自動為你建立一個安全的區塊鏈錢包。** 你不需要理解這個過程，也不需要保存任何私鑰——就像一般 app 登入一樣。

### 外部錢包

如果你已經有 MetaMask 或其他 Web3 錢包，可以直接連結，不需要建立新帳號。

---

## 第二步：進入畫布

點擊[畫布頁面](/canvas)進入 3D 空間。你會看到一個黑暗的無限空間——這是全球共享畫布，你的軌跡將永遠留在這裡。

---

## 第三步：繪製你的光軌

- **點擊並按住**開始繪製
- **移動滑鼠**（持續按住）來延伸軌跡
- **放開**暫停繪製
- 至少繪製 **10 秒**才能建立有效的存在證明

不要想太多。第一條軌跡不需要特別「有意義」——它本身就是一個時間戳，記錄你在這個時刻的移動。

---

## 第四步：提交你的證明

繪製超過 10 秒後，點擊「Submit Proof」，然後選擇證明類型。

### 標準證明（免費）

你的軌跡會與當天所有人的軌跡一起打包成 Merkle Tree，在每日 UTC 00:00 提交到 Polygon 區塊鏈。協議承擔所有 Gas 費用。你也會獲得 Time26 代幣作為參與紀錄。

| 特點     | 詳情                    |
| -------- | ----------------------- |
| 費用     | 完全免費                |
| 驗證時間 | 每日 UTC 00:00 批次處理 |
| 技術     | Merkle Tree 聚合        |
| 上鏈     | 是，透過每日批次結算    |
| 代幣獎勵 | Time26                  |

### 永恆證明（付費）

立即鑄造個人 NFT，資料同步寫入 Arweave（去中心化永久儲存）。適合想要立即取得可交易 NFT 的收藏家。

| 特點     | 詳情                     |
| -------- | ------------------------ |
| 費用     | POL 或 TIME26 代幣       |
| 驗證時間 | 即時（幾秒內）           |
| NFT      | ERC-721，鑄造到你的錢包  |
| 儲存     | Arweave 永久去中心化儲存 |
| 徽章     | 專屬收藏家徽章           |

費用結構：基本費用 + 超過 45 秒的每秒費率（前 45 秒包含在基本費用內）。

不確定選哪個？從免費的標準證明開始就對了。

---

## 提交後能做什麼？

- 在[探索](/explore)頁面找到你的證明
- 在 [Cosmos](/cosmos) 3D 視覺化中看到它
- 分享到 X、Threads 或 Instagram
- 下載截圖保存或分享

## 常見問題

**用社交帳號登入安全嗎？**

Web3Auth 使用 MPC（多方安全計算）建立錢包，不儲存你的私鑰，也不存取你的社交帳號內容。登入流程完全透過官方 OAuth 進行。

**標準證明和永恆證明的資料保存有什麼不同？**

標準證明資料暫存於協議伺服器，每日打包後上傳到 Arweave。永恆證明的資料在鑄造當下立即寫入 Arweave，不依賴我們的伺服器。兩者最終都會上鏈，但永恆證明更即時。

**如果我繪製不到 10 秒會怎樣？**

提交按鈕在達到 10 秒前不會啟用。這個下限是合約層級的限制，不只是前端的提示。

**Time26 代幣是什麼？**

POE 的原生代幣。透過標準證明的存在挖礦獲得，也可用於以 20% 折扣支付永恆證明費用。詳見[白皮書](/whitepaper)。

**能在手機上使用嗎？**

可以。建議使用桌面瀏覽器以獲得最佳繪製體驗，但手機觸控也能操作。
