# 你的數位創作會消失嗎？用區塊鏈 Proof of Existence 永久記錄你的存在

你在網路上花了數萬小時——但平台關閉的那天，一切歸零。

這不是聳人聽聞。Flickr 砍掉免費方案，數百萬張照片消失；Google+ 下線，所有貼文帶走；就連 Instagram 的限時動態，24 小時後根本找不到。雲端儲存的本質是租賃，你租的那天停止付款，或公司決定不再提供服務，你的創作就跟著蒸發。

區塊鏈解決的不是速度問題、也不是金融問題，它解決的是**永久性**問題。Proof of Existence 把你的創作時間戳與哈希值寫入不可篡改的帳本，從此那個「存在」的事實無法被任何人刪除。

本文會告訴你它怎麼運作、你的 NFT 圖片現在真的安全嗎、以及怎麼在 5 分鐘內免費建立第一筆存在證明。

> **TL;DR：** Proof of Existence 是將創作時間戳與哈希值永久寫入區塊鏈的協議。標準版完全免費，透過 Merkle Tree 每日批量結算；付費版即時上鏈並鑄造 NFT。不需要任何加密貨幣背景，用 Google 帳號登入即可開始。

## 什麼是 Proof of Existence？為什麼你需要它？

Proof of Existence（PoE）是一種密碼學協議，用區塊鏈記錄「某份文件或創作在某個確切時間點存在」的事實。根據 Polaris Market Research 的數據，數位藝術驗證的區塊鏈應用市場在 2024 年達到 3.2 億美元，並以每年 35.2% 的速度成長，預計 2034 年突破 65.14 億美元。<!-- [S] 未經原文驗證 --> 這個數字說明一件事：市場已經意識到數位創作的歸屬問題。

想像一下傳統公證處的運作：你拿著文件，公證員蓋章，說「這份合約在 2026 年 4 月 8 日存在，且內容如此」。問題是公證處可能倒閉、檔案可能失火、記錄可能被竄改。

區塊鏈做的事本質上一樣，但去掉了所有這些脆弱點。

**哈希值是關鍵。** 系統不需要儲存你的圖片本身，只需要儲存它的「數位指紋」——一串由文件內容產生的唯一字串。你的創作改變一個像素，指紋就完全不同。這個指紋一旦寫入區塊鏈，任何人都能在未來驗證：這份創作確實在那個時間點以那個確切的樣貌存在。

[原創見解] PoE 真正有力的地方不在於「我擁有它」，而在於「它曾經存在、且是這個樣子」。所有權可以轉移，但存在的事實不能被抹除。

## Arweave vs IPFS vs AWS：你的 NFT 圖片真的永久嗎？

多數人買下 NFT 的當下不知道：根據 NFT.Storage 2022 年的研究，以太坊上有 **12.8% 的 NFT metadata 已永久遺失**，約 600 萬個 NFT 無法存取，對應底價損失超過 **3.45 億美元**。另一項來自 alwaysNFT 的研究則顯示，約 **20% 的 NFT 存在損壞或過期連結**。你買的那幅「數位藝術品」，很可能只剩下一個指向空白頁面的連結。

![NFT metadata 遺失率比較（IPFS、AWS、Arweave）](/blog/poe-02-storage-compare.webp)

問題出在哪裡？出在「儲存層」的選擇。

**IPFS** 是去中心化網路，但「去中心化」不等於「永久」。IPFS 官方文件明確指出，預設的垃圾回收機制會在 **24 小時內清除**未被 pin（固定）的內容。沒有人持續付費 pin 你的文件，它就消失了。而一般網頁的平均存活時間只有 **100 天**。

**AWS S3** 更直接：這是付費訂閱服務。費率約 **$23/TB/月**（CoinGecko 2023）。專案方停止付款，你的 NFT 圖片就 404。

**Arweave** 的設計哲學完全不同。你一次性支付儲存費用，資料理論上永久保存，費用折算約為 **$2.13/TB/月**，比 AWS 便宜約 **90%**（CoinGecko 2023）。Proof of Existence 的永恆證明正是把你的完整光軌數據上傳至 Arweave，這才是真正的永久。

| 儲存方式 | 費用                         | 永久性               | 去中心化 |
| -------- | ---------------------------- | -------------------- | -------- |
| AWS S3   | $23/TB/月                    | 依付款狀態           | 否       |
| IPFS     | 免費，但需 pin               | 不保證（24 小時 GC） | 是       |
| Arweave  | 一次付清，約 $2.13/TB/月等效 | 理論永久（200 年+）  | 是       |

![Arweave 永存網示意圖](/blog/poe-02-storage-compare.webp)

## 標準證明 vs 永恆證明：選哪一個？

**標準證明完全免費**，永恆證明需支付少量的 POL 或 TIME26 代幣，兩者都把你的創作寫入 Polygon 區塊鏈。關鍵差異在於時間與完整性：標準版透過 Merkle Tree 每日批量結算，永恆版則在你提交後幾秒內即時上鏈，並同時鑄造 ERC-721 NFT 到你的錢包。Polygon 每筆交易費用約 **$0.0005–$0.002**，比以太坊低約 **1,000 倍**（Exolix），讓即時上鏈的成本真的可以接受。

**Merkle Tree 的運作邏輯是什麼？** 把它想像成一棵倒立的樹。每一筆當天的創作記錄是一片葉子，系統把所有葉子兩兩配對計算哈希，一路往上計算到唯一的「根哈希值」（Merkle Root）。這個根哈希在每天 UTC 00:00 被提交到 Polygon 鏈上。任何一筆記錄被改動，根哈希就會不同，所以即使是免費用戶，你的存在也被密碼學保護。

| 項目     | 標準證明       | 永恆證明                |
| -------- | -------------- | ----------------------- |
| 費用     | 完全免費       | POL 或 TIME26           |
| 上鏈時間 | 每日 UTC 00:00 | 即時（幾秒內）          |
| NFT 鑄造 | 否             | 是，ERC-721             |
| 儲存位置 | 協議統一管理   | 個人 Arweave + Polygon  |
| 適合誰   | 所有人         | 收藏家 / 即時驗證需求者 |

完整的操作步驟與定價說明，請參考 [/zh/learn](/zh/learn) 的詳細教學文章。

## 手把手教學：5 分鐘創建你的第一筆存在證明

不需要安裝任何程式，不需要提前購買加密貨幣。只要有瀏覽器，5 分鐘之內你就能在區塊鏈上留下第一個印記。[實際經驗] 我們測試後發現，完全沒有 Web3 背景的用戶，從打開網站到完成第一筆標準證明，平均只需要 3 分鐘。

![proofexistence.com 登入流程示意](/blog/poe-03-steps.webp)

### Step 1：登入帳號

打開 [proofexistence.com](https://proofexistence.com)，點擊右上角「登入 / 連結錢包」。

**如果你沒有加密錢包**，選擇社交登入——Google、Apple、Line、Facebook 或 X 都可以。系統會透過 Web3Auth 自動為你生成一個安全的區塊鏈錢包，全程不需要你懂任何技術。

**如果你已有 MetaMask 或其他 Web3 錢包**，直接連結即可。

### Step 2：進入 3D 畫布

登入後，點擊「[前往畫布](/cosmos)」或導航到 `/cosmos`。你會看到一片深邃的黑暗空間——這是全球共享的創作區域，所有人的光軌都會在這裡聚集。

### Step 3：繪製你的光軌

在畫布上**點擊並按住**，同時移動滑鼠（手機則是按住並滑動），開始繪製。

幾件事值得知道：系統以毫秒精度同時捕捉你的空間座標 `(x, y, z)` 和時間戳 `(t)`。每一次猶豫、加速、轉彎都被記錄。你必須繪製**至少 10 秒**才能提交——這是系統的最短時間要求，確保每一筆記錄都有足夠的「存在厚度」。

### Step 4：選擇證明類型並提交

繪製超過 10 秒後，點擊「Submit Proof」。選擇：

- **標準證明**：免費，明日 UTC 00:00 透過 Merkle Tree 結算上鏈
- **永恆證明**：支付 POL 或 TIME26，立即鑄造 NFT

確認後按下送出。系統會給你一個唯一的 Session ID。

### Step 5：查看你的鏈上記錄

提交後，你可以在 [Explore](/explore) 頁面找到你的光軌，也可以在 [Cosmos](/cosmos) 的 3D 空間中看到它的位置。標準證明用戶可在隔日後，在 Polygon 區塊鏈瀏覽器上查詢 Merkle Root，驗證你的軌跡確實被包含其中。

完整的操作說明與進階設定，請參考 [/zh/learn/getting-started/first-proof](/zh/learn/getting-started/first-proof)。

## Time26 代幣：你的時間如何變成稀缺資產？

**Time26 的總供應量為 48,420,000 枚，恰好對應 2026 年的每一秒鐘。** 這不是隨機設計——它讓代幣的稀缺性和時間本身綁定。數位藝術驗證的區塊鏈市場在 2024 年達 3.2 億美元，CAGR 35.2%（Polaris Market Research）<!-- [S] 未經原文驗證 -->，在這個背景下，Time26 代表的是一種對創作時間本身的價值主張。

稀缺性的運作方式有點反直覺：**越多人在同一個區域活動，你獲得的代幣越少；越少人到達的空曠區域，你獲得越多。** 這鼓勵探索，也確保早期參與者和邊疆探索者得到更高的獎勵。

通縮機制讓代幣的長期稀缺性有結構性支撐：協議收入的 **100%** 用於市場回購並銷毀 TIME26。每一筆永恆證明的付款，都在減少市場上的代幣總量。

## 常見問題

### Proof of Existence 和普通 NFT 有什麼差別？

普通 NFT 的核心是所有權，「這個作品屬於我」。Proof of Existence 的核心是時間性，「這個作品在這個時間點以這個樣貌存在」。兩者都使用區塊鏈，但目的不同。NFT 圖片可能因為 IPFS 連結失效而消失（研究顯示 12.8% 的 NFT metadata 已遺失，NFT.Storage 2022），但 PoE 記錄的是存在本身的密碼學證明，這個事實無法被刪除。

### 標準證明是完全免費的嗎？有隱藏費用嗎？

完全免費，沒有隱藏費用。你不需要支付 Gas 費、不需要儲值代幣、不需要信用卡。協議統一承擔 Polygon 的 Gas 費（每筆約 $0.0005–$0.002，Exolix），並透過 Merkle Tree 批量結算來攤薄成本。唯一的「成本」是你的創作時間需要至少 10 秒。

### 如果 proofexistence.com 網站關閉，我的記錄還在嗎？

標準證明的 Merkle Root 已寫入 Polygon 區塊鏈，Polygon 是去中心化的公共網路，不依賴任何單一公司的伺服器。永恆證明的完整數據則儲存在 Arweave 永存網，理論上可保存 200 年以上。即使 proofexistence.com 明天消失，你的存在記錄仍然在鏈上，任何人都能獨立驗證。

### 我沒有加密貨幣錢包，可以使用嗎？

可以。用 Google、Apple 或 Line 帳號登入，Web3Auth 會自動在背景為你建立一個安全的 MPC 錢包。整個過程你不會看到任何助記詞或私鑰的複雜設定，體驗和普通社群媒體登入沒有差別。標準證明全程不需要持有任何代幣。

### 光軌數據存在哪裡？我能下載自己的數據嗎？

你的光軌數據以 JSONB 格式儲存，包含每個時間點的 `(x, y, z, t)` 座標。標準證明的完整數據由協議統一上傳至去中心化儲存；永恆證明的數據直接寫入你個人的 Arweave 地址，完全屬於你。目前可以在 Explore 頁面查看和分享你的軌跡，下載功能的完整說明請參考 [/zh/learn](/zh/learn)。

### Merkle Tree 批量結算是什麼意思？

把它想成一個每日的「集體公證」。當天所有標準證明的軌跡被收集起來，系統計算每一筆記錄的哈希值，然後把所有哈希值兩兩配對、層層計算，最終得到一個唯一的「根哈希」（Merkle Root）。這個根哈希在 UTC 00:00 被寫入 Polygon 鏈。任何一筆原始記錄被改動，根哈希就會不同，所以整批記錄都受到密碼學保護。

### Time26 代幣在哪裡可以交易？

Time26（TIME26）是 Proof of Existence 協議的原生代幣，部署在 Polygon 網路。你可以透過創作光軌和互動活動免費賺取，也可以用它支付永恆證明的費用。關於二級市場交易的最新資訊，請查看 [/zh/whitepaper](/zh/whitepaper) 的代幣經濟章節，或關注官方公告。

### 一條光軌最少要畫多久？

最短 10 秒。這是系統的 CHECK 約束，確保每一筆存在證明都有足夠的時間厚度。沒有最長時間限制，但永恆證明的費用計算方式是：基本費用 + 超過 45 秒的每秒費用（前 45 秒包含在基本費用內）。
