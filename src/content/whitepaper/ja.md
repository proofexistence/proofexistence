# Proof of Existence：現代の叙事詩

> POEは、共有3Dキャンバス上でのあなたの動きをキャプチャし、PolygonとArweaveに永久記録します。標準証明は無料——ガス代とストレージは私たちが負担します。永続証明は$2〜$20で即座にNFTをミントします。ネイティブトークンTime26（総供給量：48,420,000）は、1年の1秒につき1トークンの割合で、描画に費やした時間に対して報酬を支払います。

## 1. 哲学：なぜこれを作ったのか

### デジタル記憶の問題

歴史は王を覚えています。征服者を覚えています。それ以外の人は消えます。

これは新しいパターンではありません。でもインターネットがそれを悪化させました。サーバーがダウンする。プラットフォームが閉鎖される。サブスクリプションが切れる。何千時間ものオンライン上の存在が、午後の間に消えてしまいます。あなたはここにいました。何かを作りました。でもインフラが止まれば、記録はゼロに戻ります。

**Proof of Existence（POE）**はそれに対する私たちの回答です。レトリックではなく、暗号学的な永続性によって。あなたの存在、あなたの時間、あなたの動き：不変の台帳に記録され、Arweaveに保存され、何世紀も先の誰でも読むことができます。

正直なところ、「反逆」という言葉が私たちの作っているものに合っているかはわかりません。もっと正確に言えば：借り物のインフラの上に物を作ることに疲れたのです。だから、生き残るのに誰の許可も要らないものを作りました。

### 集合的な記録

昔の叙事詩は一人の人間が、一人の栄光のために書いたものでした。これはそういうものではありません。

すべての参加者が一節を書きます。それらが合わさって、私たちの誰一人として一人では生み出せないものが形になります：

- **あなたが著者です。** あなたの動きがデータを生成します。
- **ブロックチェーンが記録です。** 何も上書きされません。
- **Arweaveがアーカイブです。** 一度支払えば、200年以上保存されます。

## 2. 仕組み

POEは「生存証明」をキャプチャします——共有キャンバスとのインタラクションの永久記録です。

### ステップ1：接続

ウォレットを接続します。これがキャンバス上でのあなたのユニークな識別子になります。ソーシャルログイン（Google、X、Facebook、Apple、Line）と外部ウォレット（MetaMaskなど）をサポートしています。暗号資産の経験は不要です。

### ステップ2：キャンバスに入る

無限の暗い3D空間に入ります：グローバルキャンバスです。ここでの主要な次元は時間であり、ピクセルではありません。

### ステップ3：軌跡を描く

カーソルを動かしてください。システムが記録します：

- ミリ秒単位のタイムスタンプ `(t)` 付きの位置ベクトル `(x, y, z)`
- すべての一時停止、加速、旋回
- ユニークな「光の軌跡（Light Trail）」に圧縮されます——あなたのデータ、あなたの形

すべての躊躇が記録の一部です。それは意図的な設計です。

### ステップ4：証明タイプを選ぶ

**標準証明——無料**

あなたの軌跡はサーバーに一時保存された後、その日の他の参加者のものと一緒にマークルツリーにバッチ処理され、毎日UTC 00:00にオンチェーンに提出されます。プロトコルがすべてのガス代とArweaveストレージ費用を負担します。参加の証としてTime26トークンも獲得できます。

**永続証明——有料**

あなたの軌跡は即座にArweaveに書き込まれ、Polygonスマートコントラクトによってリアルタイムで検証されます。NFT、「インスタントミンター」バッジ、そして完全に分散化された所有権を取得します——私たちのサーバーに依存しません。

費用：セッションの長さに応じて$2〜$20、またはTime26で20%割引で支払い。

## 3. 技術アーキテクチャ

この技術スタックを選んだ理由は、永続性は後から追加する機能ではないからです。基盤でなければなりません。

| レイヤー             | 技術                  | 役割                                   |
| :------------------- | :-------------------- | :------------------------------------- |
| **インターフェース** | Next.js 16 + Three.js | キャンバスのWebGL 3Dレンダリング       |
| **コンセンサス**     | Polygon (PoS)         | 高速確認、低コスト、所有権の最終記録   |
| **ストレージ**       | Arweave               | 寄付型永久ストレージ                   |
| **アイデンティティ** | Web3Auth              | ソーシャルログイン＋外部ウォレット対応 |

**なぜArweaveなのか？**

AWSやGoogle Cloudはサブスクリプション型ストレージです。支払いをやめるとデータは消えます。Arweaveは寄付型モデルを使用します：一度の支払いで、元本の投資リターンを通じて永久ストレージを賄います。永続性をテーマにしたプロジェクトにとって、他に選択肢はありません。トレードオフはコストです——Arweaveはアップロードあたりの費用が安くありません。だから標準証明の参加者にはそのコストを私たちが吸収しています。

## 4. 経済圏：通貨としての時間

### Time26（$TIME26）

Time26はPOEのネイティブトークンです。注目を表しています——あなたが実際に創作に費やした時間であり、投入した資本ではありません。

- **シンボル：** $TIME26
- **総供給量：** 48,420,000

### なぜ48,420,000なのか？

この数字は時間に直接対応しています。内訳は以下の通りです：

**ユーザー報酬（65%）——31,536,000トークン**

2026年の1秒につき1トークン。365日 × 86,400秒 = 31,536,000。年の1秒ごとに対応するトークンがあります。このサプライは完全にクリエイターのために確保されています。

**エコシステム（35%）——16,884,000トークン**

- 10,000,000（21%）——流動性プール（Uniswapとマーケット）
- 4,730,400（10%）——チーム（長期的なビルダーインセンティブ）
- 2,153,600（4%）——運営準備金（インフラ、イベント、緊急時）

合計：31.5M + 16.9M = **48,420,000**

### 獲得方法（存在マイニング）

標準証明の参加者は存在マイニングを通じてTime26を獲得します：

```
報酬 = Σ (1 TIME26 / その秒そのセクターにいる人数)
```

混雑したセクターで描く：その秒の価値の一部を獲得。空いたエリアで描く：フルの秒を獲得。これにより誰も強制せずにキャンバス全体に活動が分散します。

## よくある質問

**参加にかかる費用は？**

標準証明は無料です。すべてのガス代とArweaveストレージ費用は私たちが負担します。永続証明（即時NFT）はセッションの長さに応じて$2〜$20です。

**POEがサービスを終了したら、私のデータはどうなりますか？**

標準証明のデータはプロトコルによって毎日バッチでArweaveにアップロードされます。永続証明のデータはミント時に即座にArweaveに書き込まれます。いずれの場合も、データはPOEのサーバーとは独立してArweave上に存在します。

**Time26は何に使えますか？**

USDに対して20%割引で永続証明の支払いに使用でき、参加の記録としても機能します。このトークンは投機的なポジションではなく、貢献した時間を反映するよう設計されています。

**キャンバスはいつ閉じますか？**

2027年1月1日。その日以前に描かれたすべてのものが永久記録の一部となります。

**暗号資産ウォレットや事前の知識は必要ですか？**

いいえ。Web3AuthはGoogle、X、Facebook、Apple、Lineでのログインをサポートしており、ウォレットは自動的に作成されます。完全なセルフカストディを希望する場合は、外部ウォレット（MetaMaskなど）も使用できます。
