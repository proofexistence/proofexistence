# 存在證明：現代史詩

> POE 將你在共享 3D 畫布上的移動軌跡，永久記錄於 Polygon 和 Arweave。標準證明免費，官方承擔所有 Gas 與存儲費。永久證明費用 $2–$20，即時鑄造 NFT。原生代幣 Time26（總供應量：48,420,000）按你實際花費的時間分配，每秒鐘對應一個代幣。

---

## 1. 哲學：我們為何在此

### 數位記憶的問題

歷史記住帝王。記住征服者。其餘的人，消失了。

這不是新現象，但網路讓它變得更糟。伺服器崩潰。平台關閉。訂閱到期。數萬小時的線上存在，一個下午就蒸發了。你曾在這裡。你做了東西。但當基礎設施停止運作，紀錄歸零。

**存在證明（POE）**是我們對此的回應。不是靠口號，而是透過加密永久性。你的存在、你的時間、你的移動：記錄在不可篡改的帳本上，儲存於 Arweave，幾個世紀後的任何人都能讀取。

說實話，「反叛」這個詞我們也不確定是否準確。更像是：我們厭倦了在借來的基礎設施上構建東西。所以我們造了一個不需要請求許可就能存活的東西。

### 一份集體紀錄

古代史詩由一個人寫，為了一個人的榮耀。這不是那種東西。

每位參與者寫下一節。合在一起，形成我們任何人單獨都無法創造的東西：

- **你是作者。** 你的移動生成數據。
- **區塊鏈是紀錄。** 沒有任何東西被覆寫。
- **Arweave 是檔案庫。** 一次付費，儲存 200 年以上。

## 2. 運作方式

POE 捕捉「生命證明」——你與共享畫布互動的永久記錄。

### 第一步：連結

連結你的錢包。這成為你在畫布上的唯一識別符。我們支援社群登入（Google、X、Facebook、Apple、Line）和外部錢包如 MetaMask，不需要加密貨幣先備知識。

### 第二步：進入畫布

你進入一個無限的黑暗 3D 空間：全球畫布。這裡的主要維度是時間，不是像素。

### 第三步：繪製光軌

移動你的游標。系統會記錄：

- 位置向量 `(x, y, z)` 與毫秒級時間戳 `(t)`
- 每一個停頓、加速與圓弧
- 壓縮成獨一無二的「光軌（Light Trail）」——你的數據，你的形狀

每一個猶豫都是紀錄的一部分。這是刻意設計的。

### 第四步：選擇你的證明類型

**標準證明（Standard Proof）——免費**

你的光軌暫存於伺服器，每天 UTC 00:00 與其他人的軌跡批量打包成 Merkle Tree 後上鏈。協議承擔所有 Gas 與 Arweave 儲存費用。你獲得 Time26 代幣作為參與憑證。

**永久證明（Perpetual Proof）——付費**

你的軌跡立即寫入 Arweave，並由 Polygon 智能合約即時驗證。你獲得 NFT、「Instant Minter」徽章，以及完全去中心化的所有權——不依賴我們的伺服器。

費用：依會話時長 $2–$20，或以 Time26 支付享 20% 折扣。

## 3. 技術架構

我們選擇這套技術棧，因為永久性不是後來才加進去的功能，它必須從根基開始。

| 層級       | 技術                  | 職責                             |
| :--------- | :-------------------- | :------------------------------- |
| **介面層** | Next.js 16 + Three.js | WebGL 3D 渲染畫布                |
| **共識層** | Polygon (PoS)         | 快速確認、低成本、所有權最終裁決 |
| **儲存層** | Arweave               | 捐贈制永久儲存                   |
| **身份層** | Web3Auth              | 社群登入 + 外部錢包支援          |

**為什麼選 Arweave？**

AWS 和 Google Cloud 是訂閱制儲存：停止付費，數據消失。Arweave 用捐贈模型：一次性付款，透過本金投資報酬來維持永久儲存。對一個關於永久性的專案，沒有更好的選擇。代價是成本——Arweave 每次上傳並不便宜。這就是為什麼我們替標準證明的參與者吸收這筆費用。

## 4. 經濟：時間作為貨幣

### Time26（$TIME26）

Time26 是 POE 的原生代幣。它代表注意力——你實際花費在創作上的時間，而非你投入的資本。

- **代號：** $TIME26
- **總供應量：** 48,420,000

### 為什麼是 48,420,000？

這個數字直接對應時間，拆解如下：

**用戶獎勵（65%）——31,536,000 枚**

2026 年每一秒對應一枚代幣。365 天 × 86,400 秒 = 31,536,000。這部分完全保留給創作者。

**生態（35%）——16,884,000 枚**

- 10,000,000（21%）——流動性池（Uniswap 等交易所）
- 4,730,400（10%）——團隊（長期建設者激勵）
- 2,153,600（4%）——營運儲備（基礎設施、活動、緊急備用金）

合計：31.5M + 16.9M = **48,420,000**

### 如何賺取（存在挖礦）

標準證明的參與者透過「存在挖礦」獲得 Time26：

```
獎勵 = Σ (1 TIME26 / 該秒該區域的參與人數)
```

在擁擠的區域創作：你獲得該秒價值的一小部分。在空曠的區域創作：你獲得完整的秒值。這讓活動自然分散到畫布各處，不需要強制規則。

### 永續閥門

永久證明費用收入透過動態機制流通：

**Phase A——通縮**

時機：早期階段，或供應量穩定在 30M 以上。

100% 收入用於從公開市場回購並銷毀 $TIME26。供應減少。持有的代幣隨時間獲得稀缺價值。

**Phase B——永續**

時機：供應量低於 30M，或價格不可持續地上漲。

20% 銷毀，80% 進入國庫。國庫資助 2026 之後的運營，包括 2027 展覽階段。

這不是什麼創新機制設計。這只是一個實際的回答，針對每個加密專案都在迴避的問題：炒作過後怎麼辦？我們寧願現在就說清楚。

- **Q3–Q4：**「引力場」活動——社群共同創作大型主題畫布。

### 2027：展覽階段

畫布在 2027 年 1 月 1 日封存。

軌跡將在紐約、東京、倫敦的沉浸式展覽中展出——這是這個規模下第一個去中心化生成藝術展。每位持有存在證明的用戶，有資格鑄造含有自己軌跡全息投影的實體「時間膠囊」。

我們現在還不確定這些展覽會長什麼樣子。這種不確定性是作品本身的一部分。

### 2028+：永久檔案

所有數據留存於 Arweave。未來的研究者——人類或 AI——將在這些軌跡中找到 2026 年的行為記錄：人們做了什麼、去了哪裡、停留了多久、留下了什麼形狀。

## 常見問題

**參與的費用是多少？**

標準證明免費。我們承擔所有 Gas 和 Arweave 儲存費用。永久證明（即時 NFT）費用為 $2–$20，依會話時長而定。

**如果 POE 關閉，我的數據怎麼辦？**

標準證明數據每天關閉前由協議批量上傳至 Arweave。永久證明數據在鑄造當下即寫入 Arweave。兩種情況下，數據都存在於 Arweave，不依賴 POE 的伺服器。

**Time26 可以用來做什麼？**

以美元 20% 折扣支付永久證明費用，以及作為參與憑證。這個代幣的設計初衷是反映你貢獻的時間，而非投機部位。

**畫布什麼時候關閉？**

2027 年 1 月 1 日。在此之前繪製的所有內容，都是永久記錄的一部分。

**我需要加密貨幣錢包或先備知識嗎？**

不需要。Web3Auth 支援 Google、X、Facebook、Apple 和 Line 登入，錢包會自動建立。如果你偏好完全自我保管，外部錢包（MetaMask 等）也可以使用。
